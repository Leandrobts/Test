2. XSLT: verificação por XML

O último botão abre uma página XML local ao mesmo site, usando uma folha XSLT externa. Caso o navegador mostre "XSLT FUNCIONOU", a transformação por stylesheet foi executada. Se mostrar XML bruto ou erro, registre isso.
